# 命令行井字棋游戏

基于Python命令行开发实现的井字棋游戏。

## 实验目的
初步练习Python编程与游戏开发

## 游戏规则

1. **棋盘**: 3x3的棋盘上，两位人类玩家分别用 `O`、`X` 来表示落子
2. **先手**: X先手，交替落子，直到棋盘上没有地方或者一方胜出为止
3. **胜负关系**: 当一行/一列/对角线为同一符号时，该玩家获胜

## 使用方法

### 运行游戏
```bash
python test1_1.py
```

### 游戏操作
- 游戏开始后会显示3x3的棋盘
- 玩家X先手，然后是玩家O
- 输入坐标格式：`X,Y`（坐标取值0,1,2）
- 例如：`0,1` 表示第0行第1列

### 坐标说明
```
     0   1   2  (列)
  +---+---+---+
0 |   |   |   |
  +---+---+---+
1 |   |   |   |
  +---+---+---+
2 |   |   |   |
  +---+---+---+
(行)
```

## 功能特性

- ✅ 清晰的棋盘显示
- ✅ 输入验证（防止非法输入和重复落子）
- ✅ 自动判断胜负
- ✅ 判断平局
- ✅ 支持重新开始游戏

## 技术实现

- 使用二维列表存储棋盘状态
- 使用函数模块化设计
- 完善的错误处理机制
- 清晰的用户交互提示

## 代码结构

- `init_board()`: 初始化棋盘
- `print_board()`: 打印棋盘
- `check_winner()`: 检查是否有玩家获胜
- `is_board_full()`: 检查棋盘是否已满
- `get_player_input()`: 获取玩家输入
- `make_move()`: 执行落子操作
- `play_game()`: 游戏主循环
